# ستايل هوم للستائر والكنب

## تعديل البيانات
افتح `lib/site.ts`: رقم الهاتف/واتساب، حسابات التواصل (اختياري)، نصوص الستائر والمميزات، وقائمة صور الكنب.
الصور في `public/images`.

## التشغيل والبناء
    npm install
    npm run dev       # معاينة http://localhost:3000
    npm run build     # ينتج مجلد out/

## الرفع
- أي استضافة: ارفع **محتويات** مجلد `out/` إلى public_html.
- Vercel / Netlify / Cloudflare Pages: ارفع المشروع كما هو.
